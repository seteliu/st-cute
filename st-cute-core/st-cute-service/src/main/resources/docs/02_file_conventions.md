# 文件规约

[简体中文](./02_file_conventions.md) | [English](./02_file_conventions_en.md)

本文档说明 ST-Cute 后端通过 `ContractFile` 统一管理的各级配置文件与目录读取/写入契约规约。

---

## 📁 三级配置体系

ST-Cute 采用三级配置目录体系，层级术语与优先级（从高到低）定义为：

| 层级 | 物理位置 | 定位 |
| :--- | :--- | :--- |
| **项目级** | `{projectBasePath}/.st-cute/` | 项目专有配置，优先级最高 |
| **项目通用级** | `{projectBasePath}/.agents/` | 项目共享配置，适合提交 Git 团队统一 |
| **全局级** | `~/.st-cute/`（用户主目录） | 所有项目共享的个人基线配置 |

```text
├── ~/.st-cute/                               # 全局级配置目录 (用户主目录)
│   ├── AGENTS.md                             # 全局级通用开发指令与规范
│   ├── rules/                                # 全局级规则集目录 (一文件一规则，支持嵌套子目录)
│   ├── mcp_servers.json                      # 全局级 MCP 工具服务配置
│   ├── skills/                               # 全局级技能包目录
│   ├── hooks.json                            # 全局级生命周期钩子
│   ├── permission.json                       # 全局级权限安全规则
│   ├── config.json                           # 全局级大模型供应商与系统配置
│   ├── st-cute.db                            # SQLite 数据库
│   └── logs/http-log.log                     # 全局级 HTTP 载荷交互探针日志
│
├── {projectBasePath}/.st-cute/               # 项目级配置目录 (项目专有，优先级最高)
│   ├── AGENTS.md                             # 项目级指令与开发规范
│   ├── rules/                                # 项目级规则集目录 (一文件一规则，支持嵌套子目录)
│   ├── mcp_servers.json                      # 项目级 MCP 服务配置
│   ├── skills/                               # 项目级技能包目录
│   ├── hooks.json                            # 项目级生命周期钩子
│   ├── permission.json                       # 项目级权限安全规则
│   └── permission_local.json                 # 本地级审批加白规则 (系统自动维护，仅项目级)
│
└── {projectBasePath}/.agents/                # 项目通用级配置目录 (项目共享，适合提交 Git)
    ├── AGENTS.md                             # 项目通用级指令与开发规范
    ├── rules/                                # 项目通用级规则集目录
    ├── mcp_servers.json                      # 项目通用级 MCP 服务配置
    ├── skills/                               # 项目通用级技能包目录
    └── hooks.json                            # 项目通用级生命周期钩子
```

---

## ⚙️ 层级合并语义（两种契约模型）

统一优先级：**项目级 > 项目通用级 > 全局级**。按契约类型分两种合并语义：

### 1. 叠加型契约（Rule、Hook）

* 三层配置**全部生效**，互不覆盖
* 装载注入顺序：**项目级 → 项目通用级 → 全局级**（优先级高者注入在列表/提示词前面）

### 2. 覆盖型契约（Skill、MCP）

* 读取顺序：**全局级 → 项目通用级 → 项目级**（先读低优先，后写高优先覆盖）
* 同名条目仅保留一份，**项目级最终生效**

### 3. 例外：Permission（权限）

* 仅认 **全局级 + 项目级 + 本地级**，**项目通用级 `.agents` 完全不参与**
* 规则装载顺序：全局级 → 项目级 → 本地级；裁决时**末条优先**，等效优先级：本地级加白 > 项目级 > 全局级
* 本地级（`permission_local.json`）为系统自动维护的"人在回路"加白记录，固定写入项目级目录

## 📜 规约文件汇总表

| 契约文件名/目录名 | 说明 | 支持层级 | 合并语义 |
| :--- | :--- | :--- | :--- |
| **`AGENTS.md`** | 智能体开发规则与 Prompt 约束文件 | 全局级 / 项目级 / 项目通用级 | 叠加 |
| **`rules/`** | 规则集子目录，一文件一规则，支持 `enable` 元数据启停与嵌套子目录 | 全局级 / 项目级 / 项目通用级 | 叠加 |
| **`mcp_servers.json`** | MCP (Model Context Protocol) 外部 Server 挂载配置 | 全局级 / 项目级 / 项目通用级 | 覆盖 |
| **`skills/`** | 可插拔技能包存放目录 | 全局级 / 项目级 / 项目通用级 | 覆盖 |
| **`hooks.json`** | 工具调用前后的生命周期拦截钩子 | 全局级 / 项目级 / 项目通用级 | 叠加 |
| **`permission.json`** | 静态权限安全策略定义 | 全局级 / 项目级 | 叠加（末条优先） |
| **`permission_local.json`** | 运行时用户授权加白纪录（自动维护） | 本地级（仅项目级目录） | 叠加（末条优先） |
| **`config.json`** | 大模型供应商（Supplier）配置与参数设置 | 全局级 | - |
| **`st-cute.db`** | SQLite 核心数据库文件 | 全局级 | - |
| **`logs/http-log.log`** | 大模型 HTTP 交互日志探针 | 全局级 | - |
